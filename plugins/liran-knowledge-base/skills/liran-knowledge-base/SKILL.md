# 理然知识库

使用本插件提供的理然知识库 MCP 工具检索和读取企业内部知识。

## 工作原则

1. 开始一个新的知识库目标时先创建任务上下文，并在同一目标的后续知识工具调用中持续使用该上下文。
2. 不知道资料位置时先做知识发现或目录搜索，不要猜知识空间、节点或文档 token。
3. 已知知识空间时优先在该范围内搜索，减少无关结果。
4. 需要理解上下游资料时，可以展开对象关系后再选择文档读取。
5. 回答完成后结束任务上下文。
6. 仅依据实际读取到的企业知识作答；没有找到支持材料时明确说明。

## 推荐流程

1. 创建当前目标的任务上下文。
2. 发现知识或定位知识空间。
3. 在合适范围搜索目录。
4. 必要时展开节点或对象关系。
5. 读取最相关的飞书内容。
6. 回答用户问题，并说明信息来自哪些已读取资料。
7. 结束任务上下文。

## 输出要求

- 优先给结论，再给关键依据。
- 区分文档原始信息与基于多份资料形成的归纳。
- 对未找到、无权限或内容缺失的部分明确标注。
