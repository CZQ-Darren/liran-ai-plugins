# 理然BI数仓

使用本插件提供的理然 BI MCP 工具完成企业经营数据查询。

## 工作原则

1. 业务指标、趋势和筛选问题优先搜索指标目录，不要先猜表名或字段。
2. 需要理解指标口径时，先查看指标详情，再执行查询。
3. 需要探索底层数据时，先查看当前用户可访问的数据库、表和结构，再执行只读 SQL。
4. 所有查询都以 MCP 服务端返回的权限范围为准；不要尝试绕过行级、字段级或组织权限。
5. 如果工具返回需要授权的信息，应引导用户完成工具返回的飞书授权流程，然后重试原请求。
6. 不要把数据库内部结构、SQL 猜测或模型推断当成已验证业务口径。

## 推荐流程

### 指标分析

1. 搜索相关 BI 指标。
2. 确认候选指标的定义、维度和可用筛选。
3. 查询指标数据。
4. 基于返回数据分析趋势、异常和业务含义。

### 数据探索

1. 查看可访问数据库。
2. 查看目标数据库的表或数据库说明。
3. 查看目标表结构。
4. 仅在指标能力不能满足需求时使用只读 SQL。

## 输出要求

- 清楚区分“数据结果”“指标定义”和“分析判断”。
- 涉及时间范围时写明实际查询区间。
- 数据为空、权限不足或字段不存在时直接说明，不补造结果。
